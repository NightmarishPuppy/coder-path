# Coder Path

Браузерная игра в духе CodeCombat: пишешь код на Python или JavaScript — рыцарь идёт по острову к выходу. Для детей и взрослых, работает на телефоне и iPad без клавиатуры и без интернета.

**Играть:** https://nightmarishpuppy.github.io/coder-path/

На iPad/iPhone: открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».

Графика: [Tiny Swords](https://pixelfrog-assets.itch.io/tiny-swords) от Pixel Frog — используется в игре по лицензии автора; отдельно картинки распространять нельзя.
